# Data

## Source
NASA FIRMS (Fire Information for Resource Management System)
https://www.earthdata.nasa.gov/data/tools/firms

## What I used
- Product: VIIRS S-NPP (standard processing, archive)
- Area: Morocco (or bounding box ...)
- Period: 2025-07-01 to 2025-09-30
- Retrieved on: <today's date>
- Format: CSV

## Notes
